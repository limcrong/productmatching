This project is part of an practice module for Pattern Recognition Systems for the Graduate Certificate in Pattern Recognition Systems under NUS ISS AI Systems Masters programme

 The project will take an estimated 10 days of effort by participants. These days are not expected to be continuous and may stretch over many weeks. The overall agenda is shown below.

Day 1: Introduction, project initialization
Day 2 to 9: First presentation, project work, supervision and feedback
Day 10: Project final video presentation and report submission

A suitable project uses AI/machine learning techniques to design and build a pattern recognition system to solve a real-world problem using the skills taught in the 3 course modules.
